Practical 6.1 — HBase - CRUD Operations
=======================================

INSTALLATION & SETUP
Install Docker Desktop for Windows from https://docs.docker.com/get-started/get-docker/ and complete sign-up/verification, then restart the system.
Open PowerShell as Administrator and start the HBase container: docker run -d --name hbase -p 2181:2181 -p 16010:16010 -p 9090:9090 harisekhon/hbase
Check the status: docker ps
Open the HBase shell: docker exec -it hbase hbase shell

COMMANDS / QUERIES

Query 1 — Create HBase Namespace
create_namespace 'college'

Query 2 — List Namespaces
list_namespace

Query 3 — Configure Namespace
alter_namespace 'college', {METHOD => 'set', 'PROPERTY_NAME' => 'college'}

Query 4 — Create Student Table
create 'college:students', 'info', 'academic'

Query 5 — List HBase Tables
list

Query 10 — Add Student Marks

Query 11 — Delete Marks Value

Query 12 — Delete Student Row
