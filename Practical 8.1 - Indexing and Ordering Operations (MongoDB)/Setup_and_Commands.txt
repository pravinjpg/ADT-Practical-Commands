Practical 8.1 — Indexing and Ordering Operations (MongoDB)
==========================================================

INSTALLATION & SETUP
Open Docker and check that it is running.
Open PowerShell as Administrator and start MongoDB: docker run -d --name mongoDB -p 27017:27017 mongo
Open the shell: docker exec -it mongoDB mongosh

COMMANDS / QUERIES

use companyDB

Query 3 — Display Employee Records
db.employees.find().pretty()

Query 4 — Create Salary Index
db.employees.createIndex({ salary: 1 })

Query 5 — List Database Indexes
db.employees.getIndexes()

Query 6 — Sort Salary Ascending
db.employees.find().sort({ salary: 1 })

Query 7 — Sort Salary Descending
db.employees.find().sort({ salary: -1 })

Query 8 — Create Compound Index
db.employees.createIndex({ department: 1, salary: -1 })

Query 9 — Verify Created Indexes
db.employees.getIndexes()

Query 10 — Filter And Sort Employees
db.employees.find({ department: "IT" }).sort({ salary: -1 })

Query 11 — Remove Salary Index
db.employees.dropIndex("salary_1")
