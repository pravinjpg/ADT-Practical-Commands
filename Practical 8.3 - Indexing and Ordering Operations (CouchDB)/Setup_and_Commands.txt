Practical 8.3 — Indexing and Ordering Operations (CouchDB)
==========================================================

INSTALLATION & SETUP
1. Open Docker and check the running status.
2. Open PowerShell as administrator.
3. Start CouchDB:
docker run -d --name couchdbDB -p 5984:5984 -e COUCHDB_USER=admin -e COUCHDB_PASSWORD=admin couchdb
Check whether the CouchDB container is running:
docker ps
Check CouchDB status:
curl http://localhost:5984/
Open CouchDB Fauxton in browser:
http://localhost:5984/_utils/
Login using: Username: admin; Password: admin
4. Run the queries.

curl -X PUT http://admin:admin@localhost:5984/collegedb

Query 3 — Display All Records
curl -X POST http://admin:admin@localhost:5984/collegedb/_find -H "Content-Type: application/json" -d '{"selector":{}}'

Query 4 — Create City Index
curl -X POST http://admin:admin@localhost:5984/collegedb/_index -H "Content-Type: application/json" -d '{"index":{"fields":["city"]},"name":"city_index","type":"json"}'

Query 5 — View Existing Indexes
curl -X GET http://admin:admin@localhost:5984/collegedb/_index

Query 6 — Find Mumbai Students
curl -X POST http://admin:admin@localhost:5984/collegedb/_find -H "Content-Type: application/json" -d '{"selector":{"city":"Mumbai"},"use_index":"city_index"}'

Query 7 — Create Descending Index
curl -X POST http://admin:admin@localhost:5984/collegedb/_index -H "Content-Type: application/json" -d '{"index":{"fields":[{"marks":"desc"}]},"name":"marks_desc_index","type":"json"}'

Query 8 — Sort Marks Descending
curl -X POST http://admin:admin@localhost:5984/collegedb/_find -H "Content-Type: application/json" -d '{"selector":{"marks":{"$gte":0}},"sort":[{"marks":"desc"}],"use_index":"marks_desc_index"}'

Query 9 — Create Ascending Index
curl -X POST http://admin:admin@localhost:5984/collegedb/_index -H "Content-Type: application/json" -d '{"index":{"fields":[{"marks":"asc"}]},"name":"marks_asc_index","type":"json"}'

Query 10 — Verify Ascending Order
curl -X POST http://admin:admin@localhost:5984/collegedb/_find -H "Content-Type: application/json" -d '{"selector":{"marks":{"$gte":0}},"sort":[{"marks":"asc"}],"use_index":"marks_asc_index"}'
