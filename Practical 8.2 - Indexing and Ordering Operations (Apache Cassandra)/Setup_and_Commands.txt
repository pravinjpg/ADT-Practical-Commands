Practical 8.2 — Indexing and Ordering Operations (Apache Cassandra)
===================================================================

INSTALLATION & SETUP
1. Open Docker and check the running status.
2. Open PowerShell as administrator.
3. Start Cassandra:
docker run -d --name cassandraDB -p 9042:9042 cassandra
docker exec -it cassandraDB cqlsh
4. Run the queries.

CREATE KEYSPACE collegeDB WITH replication = {'class': 'SimpleStrategy', 'replication_factor': 1};
USE collegeDB;

Query 4 — Display All Students
SELECT * FROM students;

Query 5 — Create City Index
CREATE INDEX city_index ON students (city);

Query 6 — View Existing Indexes
SELECT * FROM system_schema.indexes WHERE table_name = 'students' ALLOW FILTERING;

Query 7 — Find Mumbai Students
SELECT * FROM students WHERE city = 'Mumbai';

Query 8 — Create Descending Table
CREATE TABLE student_marks (city text, roll_no int, name text, marks int, PRIMARY KEY (city, marks)) WITH CLUSTERING ORDER BY (marks DESC);
