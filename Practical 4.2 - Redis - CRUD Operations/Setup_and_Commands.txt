Practical 4.2 — Redis - CRUD Operations
=======================================

INSTALLATION & SETUP
Open PowerShell as Administrator and install WSL (first time): wsl --install, then restart the PC.
Set the user account as "admin" or "admin1" and password "YOUR_PASSWORD". Then run: sudo apt update, sudo apt upgrade -y, sudo apt install wsl
If already installed, check with: wsl --list --verbose
If stopped, start with: wsl -d Ubuntu
Install Redis: sudo apt install redis-server -y
Start Redis server: sudo service redis-server start
Enter the Redis CLI: redis-cli
